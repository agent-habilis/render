# Vendored themes

`tokyonight_moon.tmTheme` is the TextMate/Sublime color scheme from
[folke/tokyonight.nvim](https://github.com/folke/tokyonight.nvim)
(`extras/sublime/tokyonight_moon.tmTheme`), used to syntax-highlight `<code>`
blocks so the deck matches a TokyoNight Moon terminal.
